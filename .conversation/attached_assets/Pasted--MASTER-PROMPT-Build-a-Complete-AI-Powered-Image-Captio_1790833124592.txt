## 4. FLASK BACKEND DEVELOPMENT

Develop a complete Flask backend that handles image uploads, AI caption generation, database operations, and REST API communication.

Create a modular Flask application with the following responsibilities:

**app.py**

* Initialize the Flask application.
* Register API routes.
* Configure CORS.
* Initialize the database.
* Connect the API with the caption generation module.
* Handle errors and return appropriate JSON responses.

**extensions.py**

* Initialize SQLAlchemy and other Flask extensions.

**models.py**

* Create the database model for uploaded images and their captions.

Each image record must contain:

* Unique ID
* Unique filename
* Stored image path or storage key
* Generated caption
* Upload timestamp
* Last updated timestamp

**config.py**

* Manage environment-based application configuration.
* Separate local development and production settings.
* Configure upload limits, database connection, and other relevant settings.

Implement these REST API endpoints:

1. GET /api/health

   * Check whether the Flask backend is running.
   * Return a JSON response indicating application status.

2. POST /api/caption

   * Accept an uploaded image.
   * Validate the image type, file contents, and upload size.
   * Generate a unique filename.
   * Process the image using the AI captioning model.
   * Save the uploaded image and its caption.
   * Store the corresponding record in the database.
   * Return the image ID, filename, caption, and timestamp.

3. GET /api/images

   * Retrieve all saved image records.
   * Return image details and captions in descending upload order.

4. GET /api/images/<id>

   * Retrieve an individual image record using its unique ID.

5. DELETE /api/images/<id>

   * Delete an image record and its associated stored image.
   * Return an appropriate response when the record does not exist.

6. GET /api/images/<id>/file

   * Provide safe access to a saved image for displaying it in the frontend.

Use suitable HTTP status codes, consistent JSON response formats, and meaningful error messages.

Validate uploaded file contents rather than trusting file extensions or MIME types. Prevent unsafe filenames, path traversal, oversized uploads, and invalid image files. Do not expose internal server paths, secrets, or stack traces to users.

Use Flask-CORS with appropriately configured allowed origins. Do not use unrestricted production CORS configuration.
